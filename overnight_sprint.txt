WHAT THIS IS
  Trash Island / isle2 (Godot 4.x): a cozy recycling loop — Reef Rescue dive ->
  Upcycle bench sort -> Shop sale -> world-map portals between them. Overnight
  sprint ran 2026-11-15 .. 2026-11-19, 25 numbered iterations + dated sessions.
  Goal throughout: one continuous loop, no code-built UI, honest economy,
  persistent progress, verified by execution (live editor bridge / headless
  boots / harness suite), not assumption.

KEY ARCHITECTURE DECISIONS (all shipped)
  * No Node.new() UI anywhere — everything is an authored scene. Reusable
    pieces: wm_portal, minigame_intro, npc_dialogue, notification_queue,
    floating_text, edge_marker, quest_tracker, confirm_panel,
    achievement_banner, settings_panel, run_recap, wm_loop_path, wm_flow_dots,
    shake camera, audio_manager (scene, 8-player SFX pool + BGM crossfade).
  * GameState = single economy/save brain: cached upgrades, debounced (0.4s)
    coalesced writes + flush_save() on scene change, money API, exact-change
    spend planner (bounded backtracking over 5 materials), quests_completed,
    Harbor Hero (8 turn-ins -> one-time +1 capacity / +10 kg, guarded flag,
    legacy-save migration), lifetime trackers (clean_dives, flawless_shifts,
    best hauls/combos, golden finds).
  * SaveManager = single read-modify-write path: update_game (top-level) and
    update_nested (per-NPC dicts); schema version gate v0->v1; backup rotation
    save.json -> .bak -> .bak2 with load fallback; restore_backup() with
    backup_summary() preview and last_recovery reporting; per-slot save dirs
    with picker UI + legacy migration.
  * AudioManager autoload is a scene; volumes cached in memory, debounced
    writes, SFX pool reused (no node churn); empty_inventory.wav wired up.
  * GameSettings autoload owns reduce_motion + window pin (1152x648);
    honored by all motion-heavy effects. Volumes stay with AudioManager.
  * Save writes flow through SaveManager only; npc flags via update_nested.

ECONOMY / SHOP
  * Money is real: shop header reads wallet, sales pay $, Sell-5+ gets +25%
    bulk (guide.md aligned), Undo reverses money + lifetime earnings (not
    upcycle score) and restores goods (capacity permitting), shows bulk tag.
  * Bag upgrade sink: 60$ + 25$/level, live "Bag N kg · next M$ · you have K$".
  * Tide Report bends prices/spawns/NPC chatter (4-day deterministic
    rotation; Glass Calm = +35% shop bulk; hidden-tide mode swaps all tide
    surfaces to "The sea keeps its own counsel").

WORLD MAP / LOOP
